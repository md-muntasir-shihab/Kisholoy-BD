# KISHOLOY Project Overview

## Brand
- **Brand:** কিশলয় (KISHOLOY)
- **Business:** Single-store Bangladesh e-commerce platform
- **Market:** Bangladesh
- **Languages:** বাংলা + English
- **Currency:** BDT
- **Timezone:** Asia/Dhaka

## Primary Goal
Make customer shopping simple while making the entire business manageable from one professional admin control center.

## Stack
- **Frontend:** React 19, Vite, Tailwind CSS 4, Motion
- **Backend:** Express (Node.js), TypeScript
- **Database:** PostgreSQL (Planned, via Cloud SQL or equivalent)
- **Deployment:** Google Cloud Run (AI Studio Build platform)
